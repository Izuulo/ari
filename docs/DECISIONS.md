# Decisions

Where the PRD and the Claude Code docs disagree, the docs win. Checked against Claude Code v2.1.318 docs (hooks, statusline, plugins, tools-reference) on 2026-11-05.

## Doc discrepancies

| # | PRD says | Docs say | What ARI does |
|---|---|---|---|
| D1 | Open question: do subagent tool events carry `agent_id`? | Yes. Tool events inside a subagent carry `agent_id` and `agent_type`. | Attribute directly from the hook payload. No transcript tailing for attribution. Transcripts are read only for token totals (M3). |
| D2 | `PostToolUseFailure` "verify it exists" | Exists. `error` string; Bash/PowerShell failures start with `Exit code N`. `is_interrupt` optional. `PostToolUse` fires only on success. | Failures come only from `PostToolUseFailure` and `StopFailure`. No exit-code sniffing in `PostToolUse`. |
| D3 | Tasks from TaskCreate/TaskUpdate/TodoWrite in `PostToolUse` | The task tools are **off by default** on newer models (Opus 5.x etc.), opt-in via `CLAUDE_CODE_ENABLE_TODO_TOOLS=1`. `TaskCreated` / `TaskCompleted` hook events also exist. | Capture all three tools in `PostToolUse` plus `TaskCreated`/`TaskCompleted`. Many sessions will legitimately show `no plan yet`. |
| D4 | `SubagentStart`/`SubagentStop` give transcript path | Only `SubagentStop` has `agent_transcript_path` and `last_assistant_message`. | Store transcript path from `SubagentStop`; derive it lazily otherwise. |
| D5 | Notification → `NEEDS YOU` | `notification_type` values include `permission_prompt`, `idle_prompt`, `agent_needs_input`, `elicitation_dialog`, `elicitation_url_dialog`, plus non-blocking ones (`auth_success`, `agent_completed`, …). | Only `permission_prompt`, `idle_prompt`, `agent_needs_input`, `elicitation_dialog`, `elicitation_url_dialog` set `NEEDS YOU`. |

## Project decisions

- **State dir on macOS:** macOS has no XDG state equivalent and `~/Library/Application Support` has a space that is awkward in shell commands. ARI uses `$XDG_STATE_HOME/ari` if set, else `~/.local/state/ari`, on both macOS and Linux. Config likewise uses `$XDG_CONFIG_HOME` or `~/.config/ari/config.toml`.
- **Crate name:** `ari-cli` (available on crates.io; `ari` is taken). Binary is `ari`.
- **No arg-parsing crate:** eight subcommands and a handful of flags are parsed by hand to keep startup and binary size minimal.
- **Error resolution moves to M1:** the verdict needs "open errors" to tell `RETRYING` from `ON TRACK`, so signatures and resolution ship with the reducer in M1. M3 keeps stuck detection, burn rate, cache stats and tokens.
- **D16, which errors drive the verdict:** the PRD's "open errors → RETRYING" and "turn ended with unresolved errors → BLOCKED", taken literally, would mark a whole turn RETRYING, then BLOCKED, after one harmless failure (a `grep` with no match). ARI lets only unresolved failures among the last 10 tool results drive RETRYING, and BLOCKED requires the turn to end right after an unresolved main-agent failure. Older unresolved errors still count in `✗ N` and the panel.
- **D17, stuck rules:** PRD rule 3 (edit → run → fail ×3 on the same pair) is implied by rule 2: the same command failing 3× without a success in between is caught whatever happened between the failures. Rule 1 (same call 3× in the last 10) ignores repeats separated by a file edit, which is normal edit-test iteration, and ignores task-plan bookkeeping tools. Windows are per agent so parallel subagents don't add up.
- **D18, cache savings without a price list:** hardcoded per-model prices go stale. Unless `[prices]` is set, ARI derives the effective input price from the statusline's `total_cost_usd` and Anthropic's fixed ratios (output 5×, cache write 1.25×, cache read 0.1× input), then savings ≈ 0.9 × price × cache-read tokens. Labeled `≈`; hidden when cost is unknown.
- **D19, no binaries bundled in the plugin (PRD open question 1):** a plugin's `bin/` only reaches the Bash tool's PATH, per-platform binaries would bloat every clone, and claude.ai/Cowork refuse plugins with a top-level `bin/`. Install stays three steps: binary (`dist` shell installer to `~/.local/bin`, where Claude Code's own installer puts `claude`), plugin, `ari setup`.
- **Open question 3, row position:** default `top`, so ARI's verdict sits closest to the conversation; `position = "bottom"` flips it.
- **Open question 4, `ari watch --split`:** not built. `tmux split-window ari watch` already does it, and terminal multiplexers differ too much for one helper to be worth it.
- **Events are normalized in the hook:** each hook writes a compact ARI event (not the raw payload) so lines stay under 4 KB and secrets in tool inputs (file contents) never land on disk.
- **D20, compaction forecast threshold:** `thresholds.compact_pct` defaults to 90. Checked 2026-11-05 against local recordings: none contained a `PreCompact` event yet, so the default is unverified. It's configurable, and the forecast only shows within 10 turns, where a few points of error matter little. Revisit once recordings include auto-compactions.
- **D23, hub (spec `docs/superpowers/specs/2026-11-05-hub-design.md`):** messages between the lead and an agent ride that agent's spawn line instead of a separate route; the spawn line generalises to any number of agents. Agents show tokens, not dollars: the statusline's cost is session-wide. An agent's context percent uses the main window size (`context_window_size`, else 200k). Edit line counts are lines in and out of the edit's strings, not a diff. Rows show relative ages (`12s`, `3m`), so snapshots don't depend on the time zone. Out of scope: agent-team teammates in split panes (separate sessions, listed by `ari watch --all`), and the mailbox and task files under `~/.claude/teams` and `~/.claude/tasks`.
- **D21, plainer panel (UI audit, 2026-11-05):** the PRD's status face (`face`) now defaults to off: it repeated the verdict on the line below. The turn count, the cache bar, the unattributed `other` time and the `cost of mistakes` footer are gone: each repeated or contradicted something nearby (turns reset on `/clear` while tokens don't). Fixed errors no longer take two rows each; they fold into a count. A stale agent's glyph moved from `◌` (shared with idle) to `?`.
