# M2 Watch Panel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `ari watch` shows the full panel for the current directory's session; `--once` prints it.

**Architecture:** `sessions` finds sessions; `panel` turns (State, Usage, Config, View, clock, size) into styled lines, pure; `watch` owns the terminal and the refresh loop. The panel reuses `bar`'s helpers (`cells`, `countdown`, `spinner`, colors).

**Tech Stack:** ratatui 0.30 (crossterm backend), libc (local time), insta.

**Spec:** `docs/superpowers/specs/2026-11-05-m2-watch-design.md`

## Global Constraints

- Renders cleanly at 40 columns; no line ever exceeds the terminal width; nothing wraps.
- ≤ 10 fps while a spinner is visible, 1 fps otherwise; idle CPU < 1%.
- Terminal is always restored (raw mode off, main screen) on quit, error or panic.
- `NO_COLOR` disables styles; glyph + word always carry the meaning.
- No token/cache/burn-rate/STUCK rows until M3.

## Review Focus

- Terminal narrower than 40 or shorter than 8 rows → render what fits, no panic. Test in Task 3.
- Session has a usage.json but no events (installed mid-session) → panel renders from usage. Test in Task 3.
- Followed session ends and a new one starts in the same dir → panel switches within 2 s. Test in Task 2 (pick logic).
- Very long agent action / error message (CJK, emoji) → truncated on char boundaries by display width. Test in Task 3.
- Piping (`ari watch | cat`, no TTY) → behave like `--once` instead of failing. Covered in Task 4.

### Task 2: Sessions

**Files:** Create `src/sessions.rs`.

**Produces:** `pub struct SessionInfo { id: String, dir: PathBuf, cwd: Option<String>, last_ms: u64, ended: bool }`; `pub fn list(root: &Path) -> Vec<SessionInfo>` (most recent first; `ended` from cached state); `pub fn is_live(&SessionInfo, now_ms) -> bool` (not ended, active < 30 min); `pub fn pick(list: &[SessionInfo], cwd: &str) -> Option<&SessionInfo>` (most recent with matching cwd).

- [ ] Tests: cwd from meta.json; fallback to usage.json `workspace.current_dir` then `cwd`; ordering by events.jsonl mtime; pick ignores other dirs; ended session not live. Commit.

### Task 3: Panel

**Files:** Create `src/panel.rs`.

**Produces:** `pub struct View { expand_errors: bool, expand_agents: bool }` (`Default`); `pub fn lines(st: &State, u: &Usage, cfg: &Config, view: View, now_ms: u64, clock: &str, width: u16, height: u16, color: bool) -> Vec<Line<'static>>`; `pub fn to_plain(lines: &[Line]) -> String`; `pub fn face(v: Verdict) -> &'static str`; `pub fn local_hhmm(ms: u64) -> String`.

Layout and rules per spec. Truncate by display width (`Line::width`). Signature in words: `Bash:cargo build` → `cargo build`; `Edit:/a/b/main.rs` → `edit main.rs`; `StopFailure:rate_limit` → `api rate_limit`.

- [ ] Snapshot tests (plain text, fixed `now`, fixed `clock = "12:41"` so they don't depend on the timezone): fixture final state at 46×40 and 40×40; hand-built multi-agent state (running Explore with 14 calls, done Plan, stale agent, a fixed retried error and an open one) at 50×40; NEEDS YOU state; same multi-agent state at 50×12 (session and usage dropped); width 30 doesn't panic and no line exceeds 30. Commit.

### Task 4: `ari watch`

**Files:** Create `src/watch.rs`; Modify `src/main.rs`.

**Produces:** `pub fn run(args: &[String]) -> !`. Flags `--session <id>`, `--all`, `--once`.

Loop: `ratatui::init()` (alternate screen + raw mode + panic restore); `event::poll` with timeout 100 ms when a spinner is visible else 1 s; on key handle `q`/`Esc`/`Ctrl-C`, `e`, `a`, `Tab`; every tick reload state via `state::load_session` only when `events.jsonl` or `usage.json` mtime changed; re-pick followed session every 2 s; ring `\x07` on transition into NEEDS YOU when `bell`. `--once` or no TTY: print `to_plain`/styled lines at `COLUMNS` (default 80) × 200 and exit. No session found: a centered "waiting for a Claude Code session in <dir>" panel that keeps polling.

- [ ] Manual: run `ari watch` in a second pane during a real session; `q` restores the terminal. Commit.
