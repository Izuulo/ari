# M6 Richness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the three panel problems, then show the data ARI already receives and drops (badges, prompt cache, background tasks, resume cost, turn timeline, trends, away summary), with a two-column layout, an interactive `ari watch --all` and hook errors in `ari doctor`.

**Architecture:** New hook fields are parsed in `event.rs` and folded in `state.rs`. Statusline fields go in `usage.rs`. Transcript reading stays in `tokens.rs` (`Ledger::apply`). Trends come from the existing `limits.jsonl` samples (`burn::recent`), passed to the panel in `bar::Extras`. All drawing stays in `panel.rs` (pure) and `watch.rs`.

**Tech Stack:** Rust; no new dependencies. Snapshot tests use `insta`. `cargo-insta` isn't installed, so update snapshots with `INSTA_UPDATE=always cargo test` and read every `.snap` diff before committing.

**Spec:** `docs/superpowers/specs/2026-11-05-m6-richness-design.md`

**Branch:** `m6-richness`. One commit per task. At the end, open a PR whose body is a bullet list.

## Global Constraints

- Hook path: still one parse and one append. No new file reads.
- Statusline p95 < 50 ms. The statusline row gets no new segments; new data goes in the panel or `--all`.
- Old `events.jsonl` lines, `state.json` and `tokens.json` still load: new fields are `#[serde(default)]`; bump `state.rs` `CACHE_VERSION` 3 → 4 and `tokens.rs` 2 → 3 so caches rebuild.
- Every new payload field is optional. If it's absent, its part is omitted: no `—` placeholders.
- New glyphs are single-width and get an `--ascii` mapping in `src/ascii.rs` (`⎇`→`Y`, `↳`→`>`, `◷`→`@`, `▁▂`→`_`, `▃▄`→`-`, `▅▆`→`=`, `▇`→`#`).
- `cargo clippy --all-targets` is clean after every task.

## Review Focus

- **A session recorded before this milestone:** old events and caches load, and the panel shows the new rows empty instead of crashing (Task 4 test: an old `events.jsonl` line without `pm` folds).
- **Older Claude Code without `effort`, `prompt_cache` or `session_crons`:** each part disappears (Tasks 4, 5, 6 tests: payload without the field → no badge, no suffix, no row).
- **40-column and 14-row panes with every new row present:** nothing wraps, and turns go first, then session and usage (Task 8 test, extending `narrow_and_short`).
- **Exactly 119 vs 120 columns, and `--ascii` in two columns:** single vs two columns; every line is exactly `width` cells (Task 11 test).
- **`--all` list shrinking under the selection** (a session ends while selected): the selection clamps, `enter` on an empty list does nothing, and `esc` from an opened panel returns to the list rather than quitting (Task 12 tests).
