# M0 Capture Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `ari hook` turns hook payloads into compact per-session event lines; `ari replay` prints a recorded session; one real fixture is committed.

**Architecture:** One crate, one binary. `paths` resolves state dirs, `event` is a pure `normalize(raw, t) -> Option<Event>`, `hook` does I/O around it, `replay` reads logs back. Fixtures are raw payload recordings, so normalization changes never invalidate them.

**Tech Stack:** Rust 2021 (1.96), serde, serde_json, insta (dev).

**Spec:** `docs/superpowers/specs/2026-11-05-m0-capture-design.md`

## Global Constraints

- Hook: always exit 0, never write stdout/stderr, p95 < 15 ms.
- Event line < 4096 bytes, written with a single `write_all` on an `O_APPEND` file.
- State root `$XDG_STATE_HOME/ari` else `$HOME/.local/state/ari`; never write into the project dir.
- Retention 7 days (config arrives in M1).
- One small commit per step-group; branch `m0-capture`; PR with bullets before merge.

## Review Focus

- Huge `tool_input` (5 MB Write content) → line still < 4 KB and hook still fast. Test in Task 4.
- Empty / non-JSON stdin → exit 0, nothing written. Test in Task 4.
- `session_id` like `../../etc` → nothing written anywhere. Test in Task 2 and Task 4.
- 50 concurrent hook processes → 50 intact lines. Test in Task 4.
- Multi-byte text (emoji, CJK) at a truncation boundary → no panic, valid UTF-8. Test in Task 3.

### Task 3: `event`

**Files:** Create `src/event.rs`.

**Interfaces — Produces:**
- `pub struct Event { t: u64, e: String, a, at, tool, id, act, sig, kind, msg, path: Option<String>, h, dur: Option<u64>, ok: Option<bool>, bg: Option<u32>, task: Option<TaskRef>, todos: Option<Vec<Todo>> }` — `Serialize + Deserialize + Default + Clone + Debug`, every `Option` `skip_serializing_if = "Option::is_none"`.
- `pub struct TaskRef { id: String, subject: Option<String>, status: Option<String> }`, `pub struct Todo { c: String, s: String }`
- `pub fn normalize(raw: &Value, t: u64) -> Option<Event>` — `None` if no `hook_event_name`.
- `pub fn to_line(ev: &Event) -> String` — JSON + `\n`, guaranteed < 4096 bytes (drop `todos`, then `msg`, then everything but `t`,`e`).
- `pub fn truncate(s: &str, max_chars: usize) -> String` — appends `…` when cut.
- `pub fn fnv1a(bytes: &[u8]) -> u64`

Field rules (spec table): `act` per tool — Edit/Write/MultiEdit/NotebookEdit `editing <p>`, Read `reading <p>`, Grep `grep <pattern>`, Glob `glob <pattern>`, Bash `$ <first line of command>`, Agent `agent <subagent_type>: <description>`, WebFetch `fetch <url>`, WebSearch `search <query>`, task tools `updating plan`, `mcp__srv__tool` → `srv: tool`, else tool name. `<p>` is relative to `cwd` when inside it. `sig`: Bash `Bash:<first two whitespace tokens>`, file tools `<Tool>:<file_path>`, else `<Tool>`. `h` = `fnv1a(serde_json::to_vec(tool_input))`. Failure `msg` heuristic and `kind = "exit N"` from the spec.

- [ ] Tests using payloads from the spike capture: PreToolUse Bash (`act == "$ python3 hello.py"`, `sig == "Bash:python3 hello.py"`); PostToolUseFailure Bash (`ok == Some(false)`, `kind == "exit 1"`, `msg == "SyntaxError: unexpected EOF while parsing"`); subagent Read has `a`/`at`; TaskCreated → `task {id:"1", subject:"write script"}`; PostToolUse TaskUpdate → `task {id:"1", status:"in_progress"}`; TodoWrite → `todos`; Stop with one running background task → `bg == Some(1)`; SubagentStop → `path` + `msg`; Notification → `kind == "permission_prompt"`; payload without `hook_event_name` → `None`.
- [ ] Tests: `truncate("héllo🦀wörld", 6)` is valid UTF-8 ending in `…`; `to_line` of an event with a 10 000-char `msg` and 500 todos is < 4096 bytes and parses back.
- [ ] Implement, pass, commit.

### Task 4: `ari hook`

**Files:** Create `src/hook.rs`; Test `tests/hook.rs`.

**Interfaces — Consumes:** `paths::*`, `event::{normalize, to_line}`. **Produces:** `pub fn run()` (never panics out, never prints), `pub fn now_ms() -> u64`, `pub fn prune(root: &Path, max_age: Duration)`.

Flow per spec. `meta.json` = `{"cwd","started","transcript"}`, written only on SessionStart and only if absent. `ARI_RAW_LOG` appends `{"t","p"}`. Wrap in `std::panic::catch_unwind`, set a silent panic hook, `exit(0)`.

- [ ] Integration tests (binary via `env!("CARGO_BIN_EXE_ari")`, `XDG_STATE_HOME` = a unique dir under `std::env::temp_dir()`): valid PreToolUse → exit 0, empty stdout+stderr, one line in `sessions/<sid>/events.jsonl`; empty stdin, `not json`, bad session id → exit 0, no `sessions/` content; 5 MB Write content → line < 4096; 50 parallel processes → 50 lines that each parse; SessionStart writes `meta.json` and removes a session dir whose `events.jsonl` mtime is 8 days old (set via `File::set_modified`).
- [ ] Implement, pass, commit.

### Task 5: `ari replay`

**Files:** Create `src/replay.rs`.

**Interfaces — Produces:** `pub fn load(path: &Path) -> io::Result<Vec<Event>>` (dir → `events.jsonl`, else `raw.jsonl`; a file is read directly; `raw` lines `{t,p}` are normalized), `pub fn format(events: &[Event]) -> String`.

Line format: `{:>7}  {:<10} {glyph} {e:<18} {detail}` — offset like `+12.3s`/`+2m05s`, agent `main` or `at`, glyph `▶` pre, `✓` ok, `✗` fail, `·` other; detail = `act` / `msg` / `task` / `kind`.

- [ ] Test: `format` on fixture events → `insta::assert_snapshot!`. Missing path → error message, exit 1.
- [ ] Implement, pass, commit.
