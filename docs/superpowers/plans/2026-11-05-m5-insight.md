# M5 Insight Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `ari recap`, time split, test history with failures, file conflicts across sessions, compaction forecast, mistake cost and model per agent, all fixture-tested, zero tokens.

**Architecture:** Everything is derived from data ARI already writes. New counters fold in the reducer (`state.rs`); recap replays `events.jsonl` twice (window start, now) and diffs. Cross-session work (conflicts) and samples (forecast) live in `statusline`/`watch` with debounced cache files, like `tokens.json`. Hooks change only in `event.rs` parsing (test fail counts).

**Tech Stack:** Rust; no new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-05-m5-insight-design.md`

**Branch:** `m5-insight`, one commit per task, PR with a bullet list at the end.

## Global Constraints

- Hook path: still one parse, one append; no file reads beyond today's.
- Statusline p95 < 50 ms; cross-session reads at most every 5 s.
- Old `state.json` (v2) and old `limits.jsonl` lines still load (cache rebuild; serde defaults).
- No model names hardcoded beyond the `claude-` prefix shortening.
- Every new panel line and bar segment is hideable via `hide`.

## Review Focus

- Recap window boundaries: an event exactly at the window start, an empty window, a session with no `limits.jsonl`.
- Time split never exceeds wall time; subagent tool time not double-counted.
- Conflicts: paths compared absolute; sessions in different worktrees of the same repo are different files (that's correct, not a bug).
- Forecast hidden, not wrong, with < 3 turns of data.
- `git log` in recap: missing git, not a repo, or a slow repo (1 s timeout) never fail the command.
