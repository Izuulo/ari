# M4 Launch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `ari demo`, `--ascii`, `ari doctor`, README with GIF, and release automation, so a stranger gets from zero to value in under 2 minutes.

**Architecture:** `ascii.rs` (pure char map) is applied last by `bar` and `panel`. `watch.rs` exposes a reusable `run_tui`; `demo.rs` drives it from the bundled fixture on a virtual clock. `doctor.rs` is a list of independent checks.

**Tech Stack:** Rust; `dist` (cargo-dist) for releases; `vhs` for the GIF.

**Spec:** `docs/superpowers/specs/2026-11-05-m4-launch-design.md`

## Global Constraints

- ASCII mode output is pure ASCII except user text (paths, messages), and has the same width as the Unicode layout.
- Demo needs no network, no Claude, no state dir (it never writes to disk).
- Doctor never modifies anything.
- Releases: macOS arm64/x86_64, Linux x86_64/arm64; no tag is pushed without the owner.

## Review Focus

- Demo in a tiny terminal → same collapse rules as watch, no panic. Test in Task 2.
- Doctor with no `~/.claude` at all → every check reports a fix, exit 1, no panic. Test in Task 3.
- Doctor with a chained command that hangs → reported as timed out within the chain timeout. Test in Task 3.
- `ascii = true` set in config but `ari watch` run without the flag → ASCII anyway (config wins). Test in Task 1.
- Multi-byte user text in ASCII mode → left untouched, width math still right. Test in Task 1.

### Task 2: `ari demo`

**Files:** Create `src/demo.rs`; Modify `src/watch.rs` (extract `run_tui`), `src/main.rs`.

**Produces:** `pub fn frame_at(events: &[Event], progress_ms: u64) -> (State, Usage, Extras, u64 /*virtual now*/)`; `pub fn run(args: &[String]) -> !` with `--speed <f64>` (default 1.5), `--ascii`, `--once`. `watch::run_tui(cfg, frame: impl FnMut(View, u16, u16) -> (Vec<Line<'static>>, bool)) -> io::Result<()>`.

Synthetic usage: ctx 8% → 34%, 5h 41% → 44% with resets in 2h10m, cost $0.00 → $0.12, durations from virtual time.

- [ ] Tests: `frame_at(0)` → IDLE; at the failure → RETRYING; at end → DONE with 4/4 and two done agents; `--once` output equals the end frame; 30×10 frame doesn't panic. Commit.

### Task 3: `ari doctor`

**Files:** Create `src/doctor.rs`, `commands/doctor.md`, `tests/doctor.rs`; Modify `src/main.rs`.

**Produces:** `pub struct Check { name: &'static str, ok: bool, detail: String, fix: Option<String> }`; `pub fn checks(now_ms: u64) -> Vec<Check>`; `pub fn run(args) -> !` prints `✓ name  detail` / `✗ name  detail` + `  → fix`, exit 1 if any failed.

Checks: `binary` (first `ari` on PATH, its `--version`); `plugin` (installed_plugins.json has `ari@`; enabledPlugins not false); `statusline` (settings `statusLine.command` contains `ari statusline`); `chain` (each command: run with a sample payload, ok + ms / failed / timed out); `hooks` (newest events.jsonl mtime across sessions; ✗ if none: "start a new session or run /reload-plugins").

- [ ] Integration tests with temp `HOME`/`CLAUDE_CONFIG_DIR`/`XDG_*`: all-good setup → exit 0, five ✓; empty home → exit 1 and each failing line has a `→` fix; chain with `sleep 2` → `timed out`. Commit.
