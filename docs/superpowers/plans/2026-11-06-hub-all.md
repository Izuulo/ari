# Hub --all Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `ari hub --all` shows every live session's agents in one hub.

**Architecture:** A new `src/hub/all.rs` merges the live sessions into one synthetic `State` + `Usage` + `TokenCache`. `watch.rs` draws it through the existing `hub::lines` whenever `--all` mode has the hub open and no session open. No new renderer.

**Tech Stack:** Rust, ratatui, insta (all existing).

**Spec:** `docs/superpowers/specs/2026-11-06-hub-all-design.md`

## Global Constraints

- No new dependencies. Read-only: nothing writes to session dirs.
- Root agent: id `main`, name `you`. Session key = first 8 chars of the session id. Sub-agent ids are `<key>/<id>`.
- Top bar project `all sessions`, label `N sessions`.
- Too-small note text: `hub needs 120×30 · this window is {w}×{h} · x list`.
- Work on branch `hub-all`, small commits, one PR (repo Izuulo/ari).

## Review Focus

1. No live sessions: the combined hub draws (root only) and doesn't panic. Test in Task 1.
2. A live session with no hook events yet (empty `agents`) still gets a node. Test in Task 1.
3. Two sessions with identical agent ids and names don't collide or cross-wire messages. Test in Task 1.
4. A message `to` another session's name draws a cross-session edge; an unknown name stays unknown. Test in Task 1.
5. Too-small terminal in combined hub: `x` returns to the list and `q` quits, with no list-key confusion. Test in Task 2.

- [ ] **Step 3: Implement** `merge` and `load` in `src/hub/all.rs`, plus `pub mod all;` in `hub/mod.rs`.

  - In `ctx_of` (`hub/mod.rs`), change the non-main size to `a.ctx_size.or(i.u.ctx_size).unwrap_or(200_000)`. In `zoom::context`, change the size to `a.ctx_size.or(...)` ahead of its current chain. Keep the existing subagent `shortcut:` comment.
  - `load`: `sessions::list(root)` filtered by `sessions::is_live(s, now)`. Per session, `state::load_session`, `usage::load` and `tokens::cached`. Key = `s.id.chars().take(8)`. Name = `u.session_name`, else `u.project`, else the cwd's last segment, else key (same fallback as `watch::all_entries`).
